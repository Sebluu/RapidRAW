# RapidRAW 1.7 feature tests

All three branches target the published **v1.7.0** tag
(`00379017cb14f3fc398e69fa14b33b60af07c588`). They retain Furka's RAW development,
tone pipeline, asynchronous loading and GPU caches.

| Branch                         | Features                                                  |
| ------------------------------ | --------------------------------------------------------- |
| `test/color-harmonizer-v1.7.0` | Color Harmonizer only                                     |
| `test/effect-studio-v1.7.0`    | Effect Studio only, including the revised Local Normalize |
| `test/combined-v1.7.0`         | Both features and the existing targeted Curves picker     |

The published `pr/color-harmonizer` branch and PR #2086 remain unchanged until
the photographer has tested this release. Validation helpers stay in the test
branches. The Harmonizer feature commit is separate from the commit that adds
those helpers, so the eventual contribution can stay focused.

## Start on the laptop

```bash
cd ~/Projekte/RapidRAW-Harmonizer &&
git fetch origin &&
git switch test/combined-v1.7.0 &&
git pull --ff-only &&
npm ci &&
CARGO_TARGET_DIR="$HOME/.cache/rapidraw-cargo-target" npm start
```

Use either isolated branch above to compare one feature at a time. `npm ci` is
needed after switching to the new release's dependencies; subsequent starts can
reuse them. Cargo reuses compatible dependencies from the shared target directory
and rebuilds changed native code. The first shader compilation can take longer
than later interactions.

## Manual review

1. Compare an unedited RAW with official 1.7.0 in the same build mode and at the
   same preview resolution. Opening inactive feature panels must not change it.
2. In Color Harmonizer, test neutral strength, all presets, independent Custom
   hues, Match Dominant Hues, narrow/wide attraction, neutral protection and
   node saturation. Switch images, return to a cached image and use masks.
3. In Effect Studio, test each effect alone, then the stack. Test both whole-image
   and luminance-limited Feedback/Prism. For Local Normalize, compare 0%, 50%
   and 100% strength on textured shadows with bright water or sky in frame.
4. Exercise Furka's Highlights, Shadows, Contrast, Clarity and Structure with
   studio effects active. The derived image uses the new tone-base map.
5. In the combined branch, test the global Curves picker, native pipette cursor,
   magnifier, drag adjustment and double-click reset. The existing picker does
   not target mask curves.
6. Check undo/redo, sidecar reload, copy/paste, original comparison, crop,
   zoom/pan, second-window preview and 8/16-bit exports on RAW and JPEG.

Automated shader/GPU checks do not replace these editor tests or a performance
measurement on the laptop's Iris Xe. Existing edits can look different because
Furka changes the rendering; compare against official 1.7.0, not 1.6.9.

## A short Harmonizer video

Aim for about 60–90 seconds, using a photo with three distinct colors and some
neutral surfaces. Keep the controls and the photo visible together.

- **0–10 s:** show the source and enable the neutral Harmonizer panel.
- **10–30 s:** Custom → Match Dominant Hues; raise Strength gradually, then
  move two nodes independently so the color relationships are easy to see.
- **30–50 s:** choose a linked harmony preset, rotate it and vary Pull Width.
  Show Neutral Protection on a neutral surface.
- **50–70 s:** show a masked adjustment and toggle the subsection eye for a
  clear before/after comparison.
- **70–90 s:** finish on the photo and the chosen palette. Mention that edits
  remain nondestructive and use the same processing in preview and export.

Record this video from the tested 1.7 branch before replacing the PR's existing
demo. Human validation and the new video are pending; no PR update is published
by these test branches.
